# SAXS 归一化、背景扣除与多区间模型证据

离线 Rust/Axum/SQLite 应用。应用保存原始二维积分后的 `I(q)`、误差、曝光、厚度、透射率、缓冲液候选、仪器响应、遮罩来源及原始单位，并以不可变事件和版本化制品记录归一化、缓冲液扣除、模型候选与人工裁定。

## 运行

```sh
cargo build --all-targets
cargo test --all-targets
cargo run -- --addr 127.0.0.1:5355
```

然后打开 `http://127.0.0.1:5355`。首次启动会从仓库内 `cases/saxs-case/case.json` 载入离线案例；页面顶部的“90 秒审阅路径”按来源链、异常、候选、历史和导出顺序引导复核。

## 关键语义

- q 网格不同时永不直接相减；仅在共同 q 范围内线性插值，绝不外推。
- 扣除误差包含计数误差、曝光/透射率/仪器响应归一化不确定度和背景缩放不确定度。
- 无重叠区产生带诊断的阻断结果，不生成空泛曲线。
- Guinier 与 Porod 候选分别保留；区间重叠只作诊断，不自动拼成单一模型。
- 负强度保留并标记，不为画图而删除。
- 缓冲液版本切换、接受、否定和参数调整均产生事件；未选候选继续保留。
- SQLite 事务保证事件、版本和当前指针一起切换；写入中断只保留旧版或完整新版。
