# 散射曲线台：SAXS 归一化、背景扣除与多区间模型证据

这是一个离线的小角散射审阅案例，而不是通用表格。系统保留二维积分后的 `q/I/σ`、曝光、样品厚度、透射率、缓冲液候选、仪器响应、遮罩来源与原始单位，并为归一化、背景扣除、缩放候选和 Guinier/Porod 区间候选建立可回溯依赖图。

## 运行

```sh
cargo build --all-targets
cargo test --all-targets
cargo run -- --addr 127.0.0.1:5355
```

然后访问 <http://127.0.0.1:5355>。页面提供一条九十秒内可完成的短路径：导入核对、边界重放、分支比较、最终复核与历史版本查看。

## 固定语义

- q 网格不同时绝不逐点直接相减；仅在共同 q 范围内插值，范围外不产生派生点。
- 无重叠 q 区间时，背景扣除保持阻塞状态并保留诊断，不制造数值。
- 扣除误差同时传播归一化误差与背景缩放不确定度。
- 负强度被保留和标记，不为绘图或拟合而裁剪。
- Guinier 与 Porod 始终是独立证据；区间重叠或多候选不会自动合并成单一模型。
- 缓冲液版本、缩放版本和人工接受/拒绝均形成不可覆盖的分支；未采纳候选仍保留。
- 每次推导是独立版本，当前指针只在事务完整提交后移动。

## 离线案例包

领域材料位于 `fixtures/saxs-case/`：

- `sample.csv`、`buffer_b1.csv`：同一 q 网格的样品和缓冲液。
- `buffer_shifted.csv`：q 网格错位但有重叠区。
- `buffer_high_q.csv`：与样品无重叠区。
- `metadata.json`：曝光、厚度、透射率、仪器响应、遮罩和坐标基准。
- `scenario.json`：七类边界条件与修订/冲突脚本。

所有测试只使用这些仓库内夹具和临时数据库，不访问网络。
